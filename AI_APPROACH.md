# AI Approach

## Prompt Design
The prompt is designed to be structured and instructive. It explicitly requests four categories of insights: Summary, Action Items, Decisions, and Follow-up Suggestions. It uses few-shot-like instructions to define the JSON output format and the citation requirement.

## Citation Strategy
Every insight generated by the LLM is required to include a list of citations. Each citation consists of a timestamp from the transcript. This ensures that every claim made by the AI can be traced back to a specific part of the conversation.

## Hallucination Prevention
To prevent hallucinations, the system:
1. Uses a strict system prompt that instructs the AI to only use provided information.
2. Requires citations for every insight; if the AI cannot cite a source, it shouldn't invent the insight.
3. Uses a structured JSON response format to ensure the AI remains focused on the requested fields.

## Output Validation
The output from the LLM is parsed as JSON. If the parsing fails or the structure is incorrect, the system handles it gracefully through the global error handler.

## Known Limitations
- LLM context windows may limit the length of transcripts that can be analyzed in one go.
- Complex transcripts with multiple overlapping speakers might result in less accurate citations.
